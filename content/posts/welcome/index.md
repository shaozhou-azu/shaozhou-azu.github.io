欢迎来到 Azu 的博客。这是一篇示例文章，用来展示网站的阅读效果。

以后，这里会放上自己的学习笔记、技术探索与日常思考。

## 为什么开始记录

写下来，是整理思路的一种方式。一篇文章可以从一个具体的问题出发，逐步说明背景、观察和结论。

不必等到所有事情都想明白，再开始第一篇笔记。

## 文章可以包含什么

正文使用 Markdown 编写，可以添加**重点**、链接、列表和引用。

> 让每一篇笔记，都回答一个值得记录的问题。

### 代码示例

```python
def greet(name: str) -> str:
    return f"你好，{name}！"

print(greet("Azu"))
```
